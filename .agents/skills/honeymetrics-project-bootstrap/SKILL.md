Este repositorio usa el perfil académico: ramas auxiliares → `develop` → `QA` → `main`. Conserva reglas existentes, exige Conventional Commits, commits atómicos y aprobación manual para `main`. No hagas push, merge, cambios de protección remota, despliegues ni operaciones destructivas sin confirmación explícita.
