# Contrato de fase

Cada fase debe declarar: objetivo, entradas, alcance, archivos permitidos, archivos protegidos, comandos, criterios de aceptación, pruebas, evidencia, rollback y condiciones de detención.

La entrega debe incluir archivos, comandos, resultados, métricas, hashes, riesgos, bloqueadores y siguiente fase. La decisión de revisión es `approve`, `revise`, `reject` o `blocked`.
