# Enrutamiento de modelos

Usa Gemini Flash para trabajo operativo, determinista y verificable: inventario, scripts, tests, métricas, reportes y cambios acotados.

Usa Gemini Pro para arquitectura, seguridad, leakage, validez estadística, revisión de claims, contradicciones y promoción.

Cuando no exista integración directa, genera un prompt listo para Antigravity y espera el reporte pegado por el usuario. Nunca simules que se ejecutó un modelo externo.
