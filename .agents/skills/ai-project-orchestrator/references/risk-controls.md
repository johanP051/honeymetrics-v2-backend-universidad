# Controles de riesgo

Bloquea identidad analítica por IP, fuga train/test, datos sintéticos presentados como reales, métricas supervisadas sin etiquetas, calibración no demostrada, acciones automáticas, cambios destructivos y promoción sin aprobación explícita.

La skill global puede activarse automáticamente, pero la activación no concede permisos para producción, sistemas externos, acceso remoto ni borrado.
